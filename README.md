# Landing Page — Flávio Sousa

## Estrutura
- `index.html`
- `style.css`
- `script.js`
- `assets/img/logo.jpg` (adicione o logotipo oficial)
- `assets/img/perfil.jpg` (adicione a foto profissional)

## Antes de publicar
1. Coloque as duas imagens nos caminhos indicados, mantendo exatamente os nomes `logo.jpg` e `perfil.jpg`.
2. Abra `script.js` e substitua `55DDNUMERO` pelo número real de WhatsApp, com código do Brasil e DDD, somente dígitos. Exemplo de formato: `55` + DDD + número.
3. Confira textos, serviços e informações profissionais antes de publicar.

## Publicar gratuitamente no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets/` para a raiz do repositório.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub exibirá o endereço público do site na mesma tela.

O site usa Google Fonts e Font Awesome por CDN; essas partes dependem de conexão com a internet. As imagens do profissional são arquivos locais do repositório.
